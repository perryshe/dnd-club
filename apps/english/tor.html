TOR: English for Manager — 3-Week Intensive

Техническое задание. Версия 1.0 — 18.06.2026

1. Цель проекта

Подготовить русскоязычного менеджера по автоматизированным процессам к ведению рабочих встреч (ВКС) и деловой переписке на английском языке. Фокус — общее ведение встречи, а не глубокая техническая лексика.

2. Целевая аудитория

  • Должность: менеджер по автоматизированным процессам (SAP, MES, Честный ЗНАК, Меркурий, Xtime)
  • Текущий уровень: Intermediate (могу читать/писать, но неуверенно говорю на созвонах)
  • Доступные инструменты: ChatGPT Voice (или аналог), Python с edge-tts для генерации аудио
  • Ограничения: 2–2.5 ч/день + 2 ч в дороге (аудио)

3. Формат обучения

  • Длительность: 15 дней, 18 июня – 8 июля 2026 (без выходных, но с аудио-дайджестами на выходные)
  • Каждый день:
    • 🚗 Аудио по пути на работу (60 мин) — повтор вчерашнего + новый материал
    • 💻 Вечер: AI Voice Mode (60–90 мин) — 2 раунда активной практики
    • 🚗 Аудио по пути с работы (60 мин) — повторное слушание + самодиктант
    • 📱 В течение дня: шпаргалка в телефоне (5 мин × 2–3)
  • Структура дня: 30 мин повтор → 90 мин новое → 15 мин закрепление
  • Light version: 30 мин (только фразы + 1 AI-раунд) — для дней с цейтнотом

5. Формат файла дня (day-N.html)

Каждый day-N.html — самостоятельная страница, не зависящая от других. Содержит:

  1. Шапка: тема дня, дата, Week X, Day N
  2. Progress bar / checklist (начало / пройдено?)
  3. Повторение (Review): фразы с прошлого дня + краткий диалог + quick AI run
  4. Новые фразы (Vocabulary): 10–12 фраз с переводом, примерами, транскрипцией (опционально)
  5. AI сценарии (Practice): 2 сценария — готовый промпт для ChatGPT Voice
  6. Диалог (Dialog): скрипт meeting с участием 2–3 человек
  7. Самодиктант (Dictation): 5 русских фраз → пауза → английский
  8. Self-check: 3 вопроса (понимаю? могу повторить? могу применить?)
  9. Футер: ссылки на соседние дни, common-файлы, главную

6. Дизайн-принципы (все .html файлы)

  • Mobile-first (работает на телефоне без горизонтального скролла)
  • Тёмная тема (dark background — глаза не устают)
  • Шрифт 16px минимум, line-height 1.7
  • Никаких внешних зависимостей: нет CDN, нет JS-библиотек, нет шрифтов
  • Минимальный CSS (inline в <style>)
  • Цветовая схема: фон #0d1117, текст #e6edf3, акценты #58a6ff (синий), #f0883e (оранжевый), #3fb950 (зелёный для done)
  • Все файлы в UTF-8 без BOM

8. Принцип повторения

  • День 1: только новый материал
  • День 2+: 30 мин повторение дня N-1 → 90 мин новое
  • Повторение включает: прогон фраз, пересказ диалога, AI по вчерашней теме
  • Выходные: аудио-дайджест прошедшей недели (60 мин, без активной работы)
  • К Day 15 фразы из Day 1 повторены 14 раз (каждый день)

9. Аудио-формат (generate-audio.py)

Скрипт на Python, использующий edge-tts (бесплатно, голоса Microsoft, безлимит):

  • Вход: путь к HTML-файлу дня или флаг --week N для batch-генерации
  • Выход: mp3 в audio/
  • Структура mp3 (60 мин):
    0:00–15:00 — повтор фраз вчерашнего дня (англ + пауза 5с)
    15:00–20:00 — диалог вчерашнего дня (озвучка по ролям: David / Jenny)
    20:00–45:00 — новые фразы сегодняшнего дня (англ → пауза 4с → перевод → пауза 2с → повтор)
    45:00–55:00 — новый диалог сегодня (озвучка по ролям)
    55:00–60:00 — диктант (русская фраза → пауза 7с → английский ответ)
  • Голоса:
    Английский (основной): en-US-DavidNeural (male)
    Английский (второй): en-US-JennyNeural (female)
    Русский (диктант/объяснения): ru-RU-DariyaNeural или не используется (вся озвучка на английском)
  • Запуск: pip install edge-tts → python scripts/generate-audio.py day-01

11. Emergency Card (отдельно в cheat-sheet)

Пять фраз, которые нужно знать наизусть до автоматизма:

  1. "Let me start by going through the agenda."
  2. "Could you give us a quick update on this?"
  3. "Just to clarify, what exactly is the blocker?"
  4. "Let me summarize what we've agreed."
  5. "Action items: ... I'll send the minutes in a moment."

12. Генерация аудио — инструкция

При первом запуске:

pip install edge-tts
python scripts/generate-audio.py day-01   # один день
python scripts/generate-audio.py --week 1  # вся неделя

Выход: audio/day-01.mp3 etc. — готово для телефона, копировать на устройство через USB или облако.

13. Критерии качества

  • Все .html открываются на телефоне без горизонтального скролла
  • Все внутренние ссылки работают (index → day → common → index)
  • Каждый день имеет одинаковую структуру (чтобы не путаться)
  • Чекбоксы чек-листа кликабельны
  • Скрипт generate-audio.py обрабатывает все дни без ошибок
  • Каждый mp3 длится 55–65 минут

14. План итераций (после 15 дней)

  1. Оценка прогресса (Day 15 self-recording → разбор)
  2. Слабые зоны: усилить повтор конкретных тем
  3. Новый блок: если нужно — углубление под администрирование (SQL, оборудование)
  4. Поддержание: 1–2 раза в неделю AI-сессии без подготовки
