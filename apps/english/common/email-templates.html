✉️ Шаблоны писем (заказчик → подрядчик)

Готовые шаблоны для переписки с SAP-вендором. Замени [в скобках] на свои данные.

1. Meeting Minutes — протокол встречи с подрядчиком

Отправить после каждой встречи

Subject: Meeting Minutes — [Project/Topic] — [Date]

Dear [Vendor Team],

Thank you for the productive call today.

Attendees: [Names]

Topics discussed:
1. [Topic 1] — [brief summary]
2. [Topic 2] — [brief summary]

Key decisions:
- [Decision 1]
- [Decision 2]

Action items:
- [Vendor]: [Task] — due [Date]
- [Customer]: [Task] — due [Date]

Next meeting: [Date/Time]

Please confirm that I have captured everything correctly.

Best regards,
[Your Name]
[Your Company]

2. New Requirement — новое требование к подрядчику

Отправить при появлении нового требования регулятора

Subject: New Requirement: [Regulatory change] — impact assessment needed

Dear [Vendor Contact],

We have received a new requirement from [government body / CRPT / Mercury] regarding [description].

Summary of the requirement:
[Brief description of what changed and by when it must be implemented]

Request:
Please assess the impact on our current SAP system and provide:
1. Implementation options
2. Estimated timeline
3. Resource requirements
4. Cost estimate

Deadline for proposal: [Date]

Let me know if you need any additional information from our side.

Best regards,
[Your Name]
[Your Company]

3. Change Request — запрос на изменение

Когда меняется объём работ

Subject: Change Request #[Number] — [Description]

Dear [Vendor PM],

We request the following change to the current project scope.

Change description:
[What needs to change and why]

Reason for change:
[Regulatory update / process change / new requirement]

Affected systems:
[System names]

Requested action:
Please provide a revised proposal including:
- Updated timeline
- Impact on current budget
- Any risks or dependencies

We would appreciate your response by [Date].

Best regards,
[Your Name]
[Your Company]

4. Escalation — задержка / проблема

Когда подрядчик срывает сроки

Subject: Escalation: [Project] — [Issue] — URGENT

Dear [Vendor Management],

We are escalating the following issue that requires your immediate attention.

Project: [Project name]
Issue: [Brief description of the delay/problem]
Impact: [Business impact — production, compliance, etc.]

What we need:
1. Root cause explanation
2. Recovery plan with updated timeline
3. Measures to prevent recurrence

Deadline for response: [Date/Time]

Please treat this as urgent.

Best regards,
[Your Name]
[Your Company]

5. Follow-up — напоминание о задачах

Мягкое напоминание подрядчику

Subject: Follow-up: [Action item] — status update

Dear [Vendor Contact],

I am following up on the action item from our meeting on [Date].

Action item:
[Description of the task]

Original deadline:
[Date]

Could you please provide a status update? Let us know if you need any support from our side to complete this.

Best regards,
[Your Name]
[Your Company]

6. Proposal Request — запрос коммерческого предложения

Для нового проекта / этапа

Subject: Request for Proposal: [Project name]

Dear [Vendor Contact],

We would like to request a proposal for the following work.

Scope:
[Description of the required work]

Background:
[Relevant context — regulatory requirement, business need]

Required deliverables:
1. [Deliverable 1]
2. [Deliverable 2]
3. [Deliverable 3]

Preferred timeline:
- Proposal due: [Date]
- Project start: [Date]
- Go-live deadline: [Date]

Please include timeline, cost breakdown, and resource plan in your proposal.

Best regards,
[Your Name]
[Your Company]
