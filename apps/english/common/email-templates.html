✉️ Шаблоны писем

Готовые шаблоны для деловой переписки. Замени [в скобках] на свои данные.

1. Meeting Minutes — протокол встречи

Использовать: после каждой встречи

Subject: Meeting Minutes — [Topic] — [Date]

Hi Team,

Thank you for the productive meeting today.

Attendees: [Names]

Topics discussed:
1. [Topic 1] — [brief summary]
2. [Topic 2] — [brief summary]
3. [Topic 3] — [brief summary]

Key decisions:
- [Decision 1]
- [Decision 2]

Action items:
- [Name]: [Task] — due [Date]
- [Name]: [Task] — due [Date]

Next meeting: [Date/Time]

Please let me know if I missed anything.

Best regards,
[Your Name]

2. Issue Report — сообщение об инциденте

Использовать: критическая проблема

Subject: URGENT — [System] issue — [incident #]

Hi Team,

We are facing a critical issue with [System].

Description:
[Describe the problem — what, when, impact]

Error details:
[Error message / code / log excerpt]

Impact:
Affecting [number] users / [process] is blocked

Actions taken so far:
- [Action 1]
- [Action 2]

Next steps:
- [Name] will [task] by [time]
- Escalation to [vendor/team]

I'll keep you updated on progress.

Regards,
[Your Name]

3. Status Request — запрос статуса

Использовать: follow-up по задаче

Subject: Follow-up: [Task name] status

Hi [Name],

Could you please provide an update on [task]?

Specifically:
- What is the current status?
- Are there any blockers?
- What is the ETA for completion?

Let me know if you need any support from my side.

Best regards,
[Your Name]

4. Escalation — эскалация к вендору/поддержке

Использовать: нужна помощь внешней команды

Subject: Escalation: [System] — [Issue] — [incident #]

Dear [Support Team / Vendor],

We are escalating the following issue:

System: [System name]
Issue: [Brief description]
Incident #: [Number]
Priority: High / Critical

Details:
- Started at: [Time/Date]
- Error: [Error message/code]
- What we've tried: [Steps taken]

Requested action:
[What we need from you — investigation, fix, access, etc.]

Please confirm receipt and provide an estimated response time.

Best regards,
[Your Name]
[Company]
[Phone]

5. Change Request — запрос на изменение

Использовать: изменение прав доступа, ролей, конфигурации

Subject: Change Request: [Description] — [CR #]

Hi Team,

Please find below a change request for approval.

Change description:
[What needs to change]

Reason:
[Why this change is needed]

Systems affected:
[System names]

Risk assessment:
[Low / Medium / High] — [Explanation]

Implementation plan:
1. [Step 1]
2. [Step 2]
3. Rollback plan: [if needed]

Proposed date: [Date/Time]

Please review and approve by [Date].

Best regards,
[Your Name]

6. User Notification — уведомление пользователей

Использовать: оповестить о плановых работах / изменениях

Subject: Notification: [System] — [Action] — [Date]

Dear users,

This is to inform you about [planned maintenance / system change / new feature].

What: [Description]
When: [Date/Time]
Expected downtime: [Duration]
Impact: [What users will experience]
Action required: [If any]

We apologize for any inconvenience.

Please contact [support contact] if you have questions.

Best regards,
[Your Name]
